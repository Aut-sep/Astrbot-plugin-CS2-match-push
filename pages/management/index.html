新手引导

先完成必填配置，再按需选择推送方式。

  1. 1 数据源 必填
  2. 2 接收群 必填
  3. 3 推送与扩展 可选
  4. 4 检查完成

插件需要 PandaScore 提供 CS2 赛程。先连接数据源，再添加接收群。

  1. 打开 PandaScore 官方说明，点页面里的 Dashboard 登录或注册。
  2. 在 Dashboard 复制你的 API Token，粘贴到下方。
  3. 点「验证并继续」，所有设置会在最后一步统一保存。

Token 只保存在本地插件里，不会发到群聊，也不会在页面明文显示。

比赛提醒和赛果会自动发到你添加的 QQ 群。

  1. 先在 AstrBot「机器人」页面连好 QQ 机器人并确认在线。
  2. 填写要接收比赛提醒的 QQ 群号（纯数字，需确保机器人已在群里）。

下面这些都可以先用默认设置，以后随时能改。
