新手引导

先完成必填配置，再按需选择推送方式。

  1. 1 数据源 必填
  2. 2 接收群 必填
  3. 3 推送与扩展 可选
  4. 4 检查完成

插件需要 PandaScore 提供 CS2 赛程。先连接数据源，再配置接收群。

  1. 打开 PandaScore 官方 Token 说明，从其中的 Dashboard 入口登录或注册。
  2. 在 Dashboard 复制你的 API Token，粘贴到下方。
  3. 点击「验证并继续」。所有填写内容将在最后一步统一保存。

Token 不在页面回显。只在你点击验证时发送到插件服务器，由服务器连接 PandaScore；无需发送到聊天中。

比赛提醒和赛报会自动发送到你添加的 QQ 群。

  1. 先在 AstrBot「机器人」页面连接 OneBot QQ 机器人，确认机器人在线。
  2. 填写接收群的纯数字 QQ 群号；官方机器人扩展仅用于被动查询，不参与赛事推送。

以下全部为可选项。保持当前设置即可开始使用，之后可随时调整。

推送哪些级别的赛事

新安装默认关注 S、A 级赛事。不关注具体战队也能收到所选级别的比赛；喜欢的队伍可在「订阅管理」中用简称或中文外号搜索关注。

直播链接、开幕预告、黑名单和更多设置，可在完成后进入「推送设置」或「订阅管理」。

官方机器人扩展（可选）

普通 QQ 机器人已支持全部命令和自动推送；有官方机器人时，可再增加一个查询入口。

  • 用途：查询赛程、赛果、Major 对阵图，以及抽取今日选手。
  • 优点：支持卡片和点击按钮；共用已有数据与配置，无需再部署一套插件。
  • 限制：本插件官方端只回复用户查询，不主动发送赛事提醒、日报或赛果，也不提供管理命令。
  • 开启：先在 AstrBot 接入官方机器人；完成引导后，到「高级维护 → 官方机器人扩展」启用，选择账号和开放功能。没有官方机器人可跳过。
