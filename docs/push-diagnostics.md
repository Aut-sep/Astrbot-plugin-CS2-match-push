# 推送诊断

管理面板新增「推送诊断」页，独立面板和 AstrBot 内嵌面板使用同一份数据。

页面默认按比赛分组，每场一张卡片，战队名用主题强调色显示，有待关注问题的比赛排在前面。展开比赛可分别查看异常、比赛安排、发送结果和例行记录。可按比赛 ID 查询更早的记录。日报及全局运行记录单独显示。

展开「技术详情」可查看当时的数据和判断依据。「导出诊断记录」下载最近最多 1000 条事件和异常详情，输入比赛 ID 可缩小导出范围。

## 留下哪些证据

- 待赛与单场接口返回的比赛 ID、状态、scheduled_at、begin_at、end_at、队伍 ID/名称、赛事等级等调度关键字段。
- 默认及各群筛选结果、是否命中关注、接受的赛事等级、命中的黑名单词和推送开关。
- 取消任务前的旧快照、最新返回值、决策时刻、抓取截止时间、明确原因码、是否准备交接赛果追踪。
- 提醒安排、改期重建、手动维护、插件启动/停止、后台异常及调用栈、赛果超时。
- 每个群的发送尝试、平台失败、平台接受但回执保存失败，以及完成回执保存后的成功。
- 数据源 HTTP 错误、超时、重试次数和异常响应结构；单场错误按请求的比赛 ID 关联。
- 启动时保存调度相关代码 SHA256，便于将记录对应到实际运行代码。

例如这次出现的 `not_started` 清理路径将分别记录 `not_started_time_elapsed`（时间已过去）、`not_started_time_invalid`（时间缺失或无法解析）、`selection_rejected`（筛选未通过），不再只保留「不符合条件」一句话。即使随后删除原比赛快照，诊断中的旧、新字段仍可查询。

重复且未变化的赛程数据合并记录；关键状态变化、取消与投递事件独立留存。结构异常的字段也保留其类型，避免诊断代码先于业务代码失败。

## 自动巡检

单独的后台任务每 60 秒巡检一次，默认留 120 秒宽限：

- 已知比赛提醒到期但某个应接收群仍无成功回执，标记 `missing_upcoming`。
- 已知比赛进入开赛时段，提醒任务和赛果任务均不存在且赛果未发送，标记 `result_tracking_lost`。
- 已观察到比赛结束但应接收群仍无赛果回执，标记 `missing_finished`。
- 已进入待发状态的日报逾期，标记 `daily_overdue`。

巡检记录中包含当时是否仍有提醒/赛果任务、原计划和最近观察到的单场状态；具体取消或发送错误可在同场时间线中对应查看。相同持续异常不会每分钟重复插入事件，恢复后保留恢复记录。

巡检会复核各群当前开关、筛选、历史通知边界、冻结接收范围、明确取消/延期及显式禁止赛果恢复的设置。已成功的群不会因另一个群失败而被算作漏发；成功证据独立保存，避免原回执定期裁剪后误报。手动清空通知记录时，仅重置诊断的观察范围，保留历史诊断事件。

巡检只读现有内存和持久化数据，不请求额外接口，不补发消息，不重建业务任务，不修改推送配置或发送状态。

## 存储与故障

诊断写入插件数据目录下独立的 `push_diagnostics.sqlite3`，重启后保留。每 5 分钟按 30 天与 50000 条事件定期清理，清理间隔内可能暂时超过条数限制。SQLite WAL 会复用删除后的数据库空间。

只保存允许的比赛字段；已配置令牌、Authorization、Cookie、密码字段等会脱敏，不保存请求头、整份配置或消息正文。导出仍包含群 ID 和比赛诊断数据。

诊断写入失败不会抛出至推送流程。面板展示诊断健康状态，运行日志会限频记录存储错误；最近巡检超过 3 分钟会在页面提示。插件进程完全停止时，内置巡检也会停止，不能代替外部进程监控。

## 范围

只能检查诊断启用后观察到的比赛和已进入待发状态的日报。数据源从未返回的比赛、插件未运行期间的原始响应、以及启用前已经丢失的数据，无法重建。赛事开幕、改期、Major 阶段等通知经过公共投递流程时，会记录投递异常；当前自动漏发判断主要覆盖逐场提醒、逐场赛果和待发日报。

「缺少回执」是可观测异常，不代表已证明 QQ 用户没有收到消息。例如发送超时可能已到达平台；发送成功也仅表示平台接受并且回执已保存，无法证明终端已展示或用户已阅读。

## 离线验证

在插件目录运行：

```sh
python -m unittest discover -s tests -p test_push_diagnostics.py -q
python tools/check_push_diagnostics_ui.py /tmp/cs-diagnostics-ui
```

浏览器检查使用 Playwright 缓存中的 Chromium，也可用 CS_DIAGNOSTICS_CHROME 指定 Chrome 或 Chromium。检查使用独立临时浏览器资料和本地模拟接口，验证查询、导出、转义、手机布局、深浅色与 AstrBot 内嵌桥接，不访问真实 AstrBot、PandaScore 或 QQ。
