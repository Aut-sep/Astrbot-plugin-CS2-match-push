# QQ 官方查询扩展

插件的 OneBot（aiocqhttp）适配器保持完整功能：所有查询和管理命令、今日选手，以及按已保存规则发送的赛前提醒、日报、赛果等主动赛事通知均可使用。

QQ 官方适配器是一个**默认关闭**的可选查询扩展。启用后只处理用户主动发起的查询，并把结果回复在该次官方会话中；不会主动发送赛事通知，也不会把官方会话中的回复转发到普通 QQ 群。官方账号不提供修改普通推送配置的管理指令。

## 启用与功能

先在 AstrBot 中完成 QQ 官方机器人适配器配置，再在插件设置中启用扩展并选择已配置的官方平台账号。插件直接使用 AstrBot 已有账号，不需要在插件中重复填写 AppID 或密钥。可分别选择开放哪些入口：

- **帮助**：`/cs` 文字菜单及 `/cs帮助`。
- **赛程**：`/cs比赛 [天数/全部]`、`/cs今日赛程`、`/cs未来赛程 [天数]`。
- **Major 对阵图**：`/cs对阵图 [阶段]`。
- **赛果**：`/cs赛果 [天数]`，天数为 1–30，默认 3 天；也可用 `/cs赛果 比赛 <ID>` 查询指定比赛。
- **今日选手**：`/cs今日选手`。
- **关注列表**：`/cs关注列表`。
- **简版状态**：`/cs状态`，只返回适合查询者查看的状态摘要，不展示推送群号或测试目标。

关闭某项后，官方适配器不会提供该项查询。官方查询只回复当前对话，不更改日报、接收群、关注设置或其他推送配置。赛事赛程、对阵图和赛果结果只供查询，不会因此生成任何主动推送任务。

## 回复形式和账号选择

官方扩展默认关闭。启用扩展后，「使用图片卡片和富文本回复」默认开启。发送 `/cs` 或 `/cs帮助` 可打开功能菜单；点击功能后只收到对应查询结果。文字结果可使用 Markdown，图片与简短说明共用一次回复。关闭富回复、当前会话无法使用卡片或接口拒绝 Markdown／按钮时，会通过 AstrBot 返回普通文字和图片。菜单中的按钮会以可发送的命令显示。

Markdown 排版与官方快捷按钮是官方端的特色；赛程图片、Major 对阵图、选手照片与成就图片两端都能使用。官方端只回复用户发起的当前会话查询，不主动发送赛事提醒、日报或赛果。先在 AstrBot 连接官方机器人，再到「插件详情 → CS2 管理 → 高级维护 → 官方机器人扩展」选择账号和开放功能。

官方查询使用插件中选择的 AstrBot 平台账号处理，并只回复触发命令的官方会话。OneBot 的普通群推送目标与配置不会被官方查询修改。官方适配器不开放 `/cs设置群`、`/cs移除群`、`/cs关注`、`/cs取消`、`/cs刷新`、`/cs推送`、日报管理、测试推送等管理或投递命令；用户在官方端触发这些命令时会得到不支持的提示，不会改变普通推送配置。

## 今日选手

`/cs今日选手` 在 OneBot 和已开放该功能的 QQ 官方适配器中均可使用。OneBot 返回文字资料和本地图片。QQ 官方首次抽取时，如果启用了富回复并配置了公开照片地址，会在一张卡片中展示资料、照片和「抽取今日选手」按钮，其他群成员可点击抽取自己的选手。使用本地照片时，资料、照片和抽取命令在同一条普通回复里。官方端同日再次查询会简短提示已经抽到的选手。

每天北京时间零点开始新一轮，每个适配器用户每天最多抽取一次，同一日期的 127 人池全局不重复。池中选手抽完后停止新的分配，同日重复请求继续显示已保存的选手。

两端共用抽签数据文件 `qq_daily_players.sqlite3`。身份根据**平台账号 ID 和该平台的发送者 ID**分别识别；同一个自然人使用 OneBot QQ 号和官方 OpenID 时会被视作两个平台身份，不承诺跨平台只分配一次。事务与唯一约束保护并发抽取，修改选手资料不会改变已保存的抽取结果，图片发送失败也不会重新抽签。

备份今日选手记录时需同时保存插件数据目录中的 `qq_daily_players.sqlite3`；`cs_data.json` 和面板配置导出都不包含这些记录。建议停用插件后复制整个插件数据目录，避免复制过程中仍有抽签写入。

## 官方卡片与按钮

主页与帮助按查询类型排列按钮，只显示管理员开放的功能。「Major 对阵」与「Major 下一阶段」排在一起。查询结果只展示该项功能的内容，需要再次查看功能菜单时发送 `/cs`。

菜单每排最多两个按钮。文字查询卡片展示标题和查询结果，图片查询在一条回复里发送简短说明与图片。实际外观仍需在官方机器人客户端验收。

卡片展示游戏 ID、战队、位置、国籍、年龄及已收录的生涯成就。位置表示常见职责，不代表每张地图的固定站位；没有可靠来源的年龄或荣誉不显示为确定事实。

资料位于 `qq_players.json`，成就位于 `player_achievements.json`；照片与生成的头像分别保存在 `player_photos/` 和 `player_cards/`。当前池共 127 人，名单和来源以数据文件为准。

### 照片目录

选手卡片可使用配置的公开照片 HTTPS 地址。原照片命名为 `hltv_数字.png`，紧凑头像为 `hltv_数字_compact.png`。未配置公开地址或 QQ 拒绝卡片时，首次抽取会使用本地照片回复。只需公开照片文件。配置方式可参考同目录的 [Nginx 静态目录示例](qq-player-photos.nginx.conf)。

PandaScore Token、赛程和图片缓存、选手资料及抽签池由插件各适配器共用；官方查询不另建一份独立数据，也不会修改 OneBot 的推送配置。此文档说明功能和预期行为，不代表已完成真实 QQ 消息或平台权限测试。
