# QQ 官方适配器说明

插件支持 `qq_official` 和 `qq_official_webhook`，并保留 OneBot（`aiocqhttp`）适配器。QQ 官方机器人可通过菜单按钮使用 CS 查询；赛程查询也可直接使用 `/cs比赛 [天数]`、`/cs今日赛程` 和 `/cs未来赛程`。Major 图入口为 `/cs对阵图`。菜单按钮只在 QQ 官方适配器中显示。

## 官方消息推送

在 AstrBot 管理面板中选择 QQ 官方机器人作为推送平台。官方群使用 OpenID，与 OneBot 数字群号不同。管理员在目标群 @机器人发送 `/cs设置群` 可登记当前官方群；也可在管理面板填写已知 OpenID。多机器人环境应在设置中选择正确的平台实例。

官方主动消息按所选适配器发送；失败时不会改用其他机器人。平台权限、审核或频控导致的失败会记录在推送日志中。AstrBot 内嵌管理页面使用宿主登录；独立 Web 面板本机和远程访问都需要有效面板令牌。

## 今日选手

`/cs今日选手` 是 QQ 官方专属功能。官方菜单的“今日选手”按钮可打开抽取；每个官方用户每天最多分配一位，同一天的 127 人选手池全局不重复。池中选手分配完后，当天停止新的分配；重复点击会显示已保存的选手，不重新抽签。日期按北京时间零点切换。

抽签记录保存在插件数据目录的 `qq_daily_players.sqlite3`，独立于赛程设置和推送状态。数据库事务和唯一约束保护并发分配；修改资料不会改变已经保存的抽签结果。头像或消息发送失败不会重新抽签。

卡片展示游戏 ID、战队、位置、国籍、年龄及已收录的生涯成就，并提供返回菜单和再次查看入口。位置表示常见职责，不代表每张地图的固定站位。没有可靠来源的年龄或荣誉不显示为确定事实。

选手资料位于 `qq_players.json`，成就资料位于 `player_achievements.json`；照片与生成的卡片分别保存在 `player_photos/` 和 `player_cards/`。名单与来源说明以数据文件为准，当前池为 127 人。修改照片目录或公开地址前请备份这些文件。

### 公开照片目录

选手卡片优先使用插件配置 `qq_player_photo_base_url` 指定的 HTTPS 图片目录。照片文件使用 `hltv_数字.png` 命名，紧凑头像使用 `hltv_数字_compact.png`。若未配置公开地址或远程图片无法发送，插件会回退到本地图片发送。

可参考同目录的 [Nginx 静态目录示例](qq-player-photos.nginx.conf)：将照片及生成卡片放入示例目录，并把 `qq_player_photo_base_url` 设置为对应 HTTPS 路径。仅公开图片文件；不要将抽签数据库、配置文件或面板令牌放入静态目录。

名单、照片或公开访问发生变化后，实际平台呈现还需由维护者在自己的 AstrBot 和 QQ 环境中确认。
