# 战队队标来源

核实日期：2026-10-13。这里记录核实当天官方页面和品牌素材中确认的战队图形队标；发布日期不等于核实日期，也不保证之后发生的品牌更新会自动同步。

优先使用本地的已核实官方队标；未收录、无法核实或资源不可用时使用赛事 API 队标。API 队标没有被存入本目录。

选择素材时优先核对 CS 主队和官方主标识，不把官网导航栏的黑白版、联名周边徽章或其他游戏分部标识当成比赛队标。官方规范本身采用黑白标识的战队保留原色，例如 [Team Spirit 品牌规范](https://teamspirit.gg/press-kit_EN.pdf)。

原始图形仅做 SVG/WebP 转 PNG（Legacy 图形来自官方手册的 Icon 矢量路径）、去除透明空白和等比缩小，保留图形与颜色；不添加阴影、渐变、外描边或重绘。各队商标与品牌资产归其原权利人所有，仅用于赛事信息中的战队识别。

当前收录 **56 支战队/俱乐部**，包含常见队名别称。搜索、赛程和图片通知使用同一份队标索引；浅色队标自动配深色底，深色队标配浅色底。
