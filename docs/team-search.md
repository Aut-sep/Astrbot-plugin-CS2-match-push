# 战队搜索与常看战队

支持英文全名、常见缩写、已收录中文别称、部分名称和少量拼写错误。短缩写（如 PV、RA）只做完整匹配，避免误命中其他队伍。明确输入 NAVI Junior 等队名时仍能找到青训队；输入 NAVI 等俱乐部别称时优先显示核实过身份的主队。

索引含 62 个战队/俱乐部条目，其中 60 个主队身份已于 2026-10-13 使用 PandaScore CS2 数据核对。对同名 Legacy、Falcons、Aurora 等额外核对阵容与地区；不凭搜索列表第一行选主队。身份不明确的条目不加入快捷关注，仍可从实时搜索结果自行选择。

常看战队区提供 32 支队伍，包含长期强队和编辑补选的观众熟悉队伍；不表示实时人气统计，不展示名次和排名日期，不会自动订阅。只有按下关注按钮才会保存真实战队 ID。API 请求异常时已核实主队仍可查找；未收录队伍继续实时搜索。
