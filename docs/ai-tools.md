# AstrBot AI 工具：CS2 赛程、赛果、关注与 Major 对阵

插件提供四个只读 LLM Function Calling 工具，让 AstrBot 的模型在回答自然语言问题时获取 PandaScore 数据。比赛筛选、比分校验、Major 阶段选择仍由插件执行，AI 负责理解问题和组织回答，不接管推送调度或配置。

## 使用条件

- AstrBot 的对话模型及其供应商需要支持 tool calling，并在宿主的工具管理中启用对应工具。以 AstrBot 4.29.4 的 `filter.llm_tool` 注册接口为依据实现；其他版本请确认支持该接口。
- 赛程、赛果和 Major 查询需要插件已配置有效 PandaScore Token；API 权限、额度、服务延迟和收录范围仍会影响结果。关注列表只读本地配置，不需要 Token。
- OneBot 普通机器人可使用；QQ 官方端仍要求管理员启用官方扩展、选择当前平台账号并开放相应查询功能。工具不能绕过这些限制，也不会突破官方平台自身的模型/消息限制。
- 这些是 AstrBot 内部工具，没有额外开放外网 HTTP API。注册工具不保证每次提问模型都会调用，也不会自动让外部 AI 搜索引擎发现或推荐插件。

## 工具和参数

| 工具 | 参数 | 返回范围 |
| --- | --- | --- |
| `get_cs2_schedule` | `team=""`, `start_date=""`, `days=1` | 指定计划开赛日期内的比赛，包含进行中、已结束、取消等来源状态，不能将所有条目都说成“即将开赛” |
| `get_cs2_match_result` | `team=""`, `start_date=""`, `days=1`, `match_id=""` | 时间范围内已结束比赛；指定比赛 ID 时返回该场实际状态，未结束时不提供最终比分 |
| `get_cs2_followed_teams` | 无 | 当前群适用的关注列表；非已配置 OneBot 群使用默认规则，不是提问者的个人收藏 |
| `get_cs2_major_bracket` | `stage="current"` | 当前、下一、全部或指定 Major 阶段的已公布对阵及明确晋级关系，返回文字结构，不绘图 |

`team` 支持内置精确别名（例如“绿龙”对应 Spirit、“NAVI”对应 Natus Vincere）、战队全名、slug 或 PandaScore ID。查询不做模糊拼写猜测；不唯一的别名要求澄清。未收录别名可改用正式队名或 ID。

所有日期均为 **Asia/Shanghai（北京时间，UTC+08:00）**。`start_date` 为 `YYYY-MM-DD`，`days` 为整数 1–30，日期范围含起始日、不含结束日，依据**计划开赛时间**，不是比赛结束时间。赛程日期留空从今天起算；赛果日期留空回看含今天的最近 `days` 天。按比赛 ID 查询时忽略日期参数。

示例：问“今晚绿龙有没有比赛”，模型应以北京时间今天的日期调用 `get_cs2_schedule(team="绿龙", start_date="2026-11-04", days=1)`，再根据比赛时间判断今晚的场次；问“昨天 NAVI 赢了吗”，在 2026-11-04 提问时调用 `get_cs2_match_result(team="NAVI", start_date="2026-11-03", days=1)`。上述日期仅作示例，模型必须随实际提问日期调整。

赛程和赛果沿用当前群或默认的赛事级别、关注模式和黑名单，所以空列表只表示**此筛选及时间范围内未收录符合条件的比赛**。Major 保持整届赛事的已公布对阵，不套用普通赛程筛选。`current` 无进行中阶段时回退到 `next`，返回 `requested_stage` 和 `selected_stage` 明确区分；赛事本身沿用正在进行、即将开始、最近结束的选择顺序，以返回标题为准。瑞士轮不会推断后续对手。

## 数据真实性和只读边界

每次调用均返回 JSON 字符串，包含：

- `status`：`ok`、`invalid_request`、`not_configured`、`denied` 或 `unavailable`。
- `timezone`、`source`、`queried_at`：使用时区、数据来源和工具调用时间。
- `fetched_at`：成功读取完整数据的时间，失败时为 `null`；它不代表赛事数据在来源端的最后修改时间。
- `data_updated_at`：来源最后修改时间未知时为 `null`。比赛条目中如有 PandaScore `modified_at` 则单独返回；聚合数据及本地配置没有可确认的统一修改时间，保持 `null`。
- `is_cached`：当前实现始终为 `false`。远程工具每次直接读取 API，不复用后台赛程、图片或 Major 缓存；本地关注工具直接读取当前配置。数据源自身可能存在延迟。
- `data`：查询成功的数据；失败时为 `null`，同时给出 `error`。空列表与查询失败严格区分。

普通比赛最多返回 100 场，Major 每阶段最多返回 100 场，超过时包含 `total` 和 `truncated=true`，不应称为完整结果，可缩小日期或指定战队。比分仅在已结束且通过现有比分校验后提供，缺失或不完整时 `final_score=null`，不能自行补全胜负。来源没有公布的比赛、比分或晋级关系均不得推断。

工具不能更改配置、添加关注、管理接收群、启动刷新调度或向群发消息；没有接收其他群 ID、Token、任意 URL 等参数。只返回当前会话适用的关注信息，不返回平台账号、群列表、面板令牌或 API 凭据。远程异常只返回通用错误，避免把敏感 URL 或凭据带给模型。

## 验证与合并

新增工具以替代 API 和事件进行离线检查，覆盖日期边界、状态区别、中文别名、群规则隔离、官方端拒绝、结果截断和不写入数据。未操作真实 AstrBot/QQ 界面或发送测试消息，宿主工具发现、模型实际调用和客户端回复效果由维护者验收。新工具通过 `main.py` 注册；前端资源没有修改，可在前端调整完成后合并功能分支。
