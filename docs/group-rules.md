# 每群推送规则

从 4.3.2 起，普通 QQ 接收群可以分别设置推送规则。在 AstrBot「插件详情 → CS2 管理 → 订阅管理」添加接收群后，点击群旁的“编辑规则”，或在默认赛事范围下方的“群推送规则”中选择群。

## 从预设开始

选择接收群后，可以先应用一套预设，再按自己的习惯调整：

| 预设 | 用途 | 基础配置 |
| --- | --- | --- |
| 大赛观众 | 提醒观看 S 级大赛 | S 级，提前 10 分钟提醒，开启赛果和改期，关闭日报 |
| 主队粉丝 | 跟进关注战队的比赛 | 只看所选战队，不限赛事级别，提前 10 分钟提醒，开启赛果和改期，关闭日报 |
| 赛事资讯群 | 提供每日赛事资讯 | S/A 级，每天北京时间 08:00 发送当天赛程，开启赛果，关闭逐场赛前和改期 |

三套预设都默认开启图片、赛事开幕通知（提前 2 小时）和 Major 阶段提醒。赛事开幕按群赛事范围筛选；Major 阶段提醒展示完整阶段，不限主队，两种提醒可同时发送。所有开关都可以继续调整。

应用预设会将规则复制到当前群；内置预设保留当前群的黑名单，自定义预设使用保存的完整规则。点击页面的“保存配置”后生效。主队粉丝需要至少选择一支战队。其他群和全局默认规则不受影响。

调整好当前群后，可以另存为自定义预设并命名；自定义预设支持更新、重命名、另存副本和删除。预设库的修改也通过页面的“保存配置”统一保存。以后应用到其他群时，会复制为该群的独立规则；修改或删除预设不会覆盖已经配置好的群。

自定义预设仅保存推送规则，不包含 Token、接收群号、机器人账号和发送记录。预设库由本插件的管理面板统一管理，配置导入导出包含自定义预设。

## 默认规则与本群自定义

新群默认继承现有设置。选择群后，在“赛事范围”“比赛通知”“赛程日报”“消息样式”之间切换。每项勾选“独立设置”即可编辑本群值，取消勾选恢复继承：

- 沿用默认：以后修改默认值，该项一起变化。
- 本群自定义：该项只使用本群值，不跟随默认值变化。
- 自定义为关闭、空关注列表或空黑名单，是明确设置，不会被当作继承。

上方的“默认关注战队”“默认赛事范围”以及“推送设置”编辑默认值。群规则可以只覆盖几项，其余继续继承。修改、切换群及复制都只暂存于页面；点击全局“保存配置”后才生效，“放弃全部修改”恢复已保存的内容。

## 可设置项目

| 项目 | 用法 |
| --- | --- |
| 自动推送总开关 | 暂停本群自动通知，保留关注和规则；不影响其他群 |
| 比赛筛选方式 | 按赛事级别、只看关注战队、赛事级别或关注战队 |
| 赛事级别 | S、A、B、C、D 或未评级，可以多选或留空 |
| 关注战队 | 独立搜索并选择本群关注战队，沿用简称、中文别称及拼写容错 |
| 战队／联赛黑名单 | 关键词匹配，始终优先于关注和赛事级别 |
| 赛前提醒 | 独立开启或关闭；提前分钟数由用户填写，1–120 的整数 |
| 赛后结果、改期通知 | 分别开启或关闭；改期沿用临近两小时过滤及同批汇总 |
| 赛事开幕通知 | 独立开关及提前 1–168 小时 |
| Major 阶段提醒 | 开赛前 2 小时内提醒，可独立开启或关闭，不按主队裁剪 |
| 日报 | 独立开关、多个北京时间发送时刻和 1–30 天赛程范围 |
| 图片消息 | 开启使用图片，关闭采用文字模式 |

赛前提醒的优先级为：**单场自定义提醒 → 本群提醒 → 默认提醒**。单场设置仍是该场比赛的统一覆盖；取消单场覆盖后，各群恢复自己的提醒时间。

例如，A 群只看 NAVI、提前 23 分钟提醒；B 群只看 S 级赛事、提前 7 分钟提醒，并关闭日报。这里的分钟数只是填写示例，可以在允许范围内自由修改，同场比赛的赛果追踪不受提醒时间差异影响。

## 复制与恢复

展开群规则底部的“复制与恢复”，点击“复制完整规则”将来源群当前生效的设置复制为目标群的独立值。复制后两个群互不联动；若希望某项继续跟随默认值，可取消该项的“独立设置”。

“全部恢复继承”会清除该群的独立设置，确认并保存后生效，不删除接收群。

## 查询、测试和手动推送

- 普通接收群的 `/cs比赛`、`/cs赛果` 和 `/cs关注列表` 按本群规则查询。`/cs群规则` 只显示本群配置，不提供普通成员修改入口。
- 私聊、未配置为接收群的会话和 QQ 官方查询使用默认规则。官方端不开放主动推送或规则管理。
- 赛事工具可以选择默认规则或某个群，预览只在页面展示，不向 QQ 发送消息。
- 测试可以选择采用哪套群规则，但始终只发送到已保存的测试目标，不会因此发往该规则所属群。
- 立即推送可以选择一个群或全部启用的接收群；内容分别按各群规则筛选，手动推送不要求开启定时日报。
- Major 对阵图不按关注战队裁剪，保持完整阶段；图片或文字展示按选定规则处理。今日选手继续使用原有共享选手池。

原有 `/cs关注`、`/cs取消`、`/cs提醒`、`/cs延迟通知`、`/cs日报` 管理命令继续编辑默认规则；本群已覆盖的项目不受影响。修改独立规则优先使用面板。

## 发送与升级说明

每场比赛共用上游数据和赛果追踪，各群独立投递。改期汇总按各群实际需要接收的场数计算，某群已收到赛前提醒不会让其他群被误判为已提醒。日报按群、日期和发送时间分别记录，失败重试保持原内容，跳过成功目标。

暂停或移除群后，发送前会重新检查。修改规则默认不补发已错过的通知；新群不会加入旧赛果或旧日报的失败重试。已经收到的通知记录保留，不会因为普通规则编辑被清空。发送成功到回执保存之间发生进程中断，仍可能重发。

PandaScore Token、获取范围、刷新周期和推送机器人实例继续共用。日报填写 7 天不会自动把默认 2 天的赛程获取范围扩大到 7 天，需要时先调整 `fetch_ahead_days`。

旧配置无需手工转换，旧群继续继承原设置，发送记录和抽签数据库保留。升级前停用插件并备份整个 `data/plugin_data/astrbot_plugin_cs_match/`，至少保存 `cs_data.json` 和已生成的 `qq_daily_players.sqlite3`。导出配置包含群规则，不包含凭据、通知状态和抽签数据库；回退旧版请使用升级前备份。
