# 推送配置

在「订阅管理」添加接收群后，使用同一个配置库选择、编辑和保存推送规则。

[返回首页](../README.md)

## 选择一套配置

| 配置 | 用途 | 基础设置 |
| --- | --- | --- |
| 默认配置 | 通用赛事提醒与比分推送 | 使用当前默认设置，可编辑或另存 |
| 大赛观众 | 提醒观看 S 级大赛 | S 级，提前 10 分钟提醒，开启赛果和改期，关闭日报 |
| 主队粉丝 | 跟进关注战队的比赛 | 只看所选战队，不限级别，提前 10 分钟提醒，开启赛果和改期 |
| 赛事资讯群 | 提供每日赛事资讯 | S/A 级，每天北京时间 08:00 发送当天赛程，开启赛果，关闭逐场赛前和改期 |
| 我的配置 | 保存自己的观赛习惯 | 按需调整、命名并复用 |

大赛观众、主队粉丝和赛事资讯群均默认开启图片、赛事开幕通知（提前 2 小时）与 Major 阶段提醒。两种开幕提醒独立发送，Major 阶段对阵不按主队裁剪。

选择接收群，将配置应用到该群后，可以直接调整下方各项设置。主队粉丝需选择至少一支战队。点击页面的“保存配置”后生效，修改不会影响其他群。

默认配置也在同一处编辑。在面板修改默认配置时，已有群会保留修改前的有效设置；需要让某个群使用新设置时，再将默认配置应用到该群。

## 保存自己的配置

调整好当前配置后，点击“另存为我的配置”并命名。自定义配置支持更新、重命名、另存副本和删除。

配置应用到群后会复制为完整设置。修改或删除配置库中的条目，不会覆盖已应用到其他群的内容。内置观赛配置保留目标群的黑名单；默认配置和自定义配置使用保存的完整规则。

配置只保存赛事筛选、关注战队、通知、日报和消息样式，不包含 Token、群号、机器人账号和发送记录。配置库与群配置均通过页面的“保存配置”统一保存，“放弃全部修改”恢复已保存的内容。

## 可调整的内容

| 项目 | 用途 |
| --- | --- |
| 赛事推送 | 开启或暂停该群全部赛事推送，仍可主动查询 |
| 赛事范围 | 关注战队、赛事级别、筛选方式及战队／赛事黑名单 |
| 比赛通知 | 赛前提醒、赛后比分、改期、赛事开幕与 Major 阶段提醒 |
| 赛程日报 | 开关、多个北京时间发送时刻、1–30 天赛程范围 |
| 消息样式 | 图片或文字消息 |

单场自定义提醒时间优先于群配置。日报天数不会自动扩大赛程获取范围，需要时在高级维护中调整获取天数。

## 查询与备份

普通接收群的查询使用本群配置；私聊、未配置的群和官方机器人查询使用默认配置。赛事工具可选择默认配置或某个群的配置。预览不发消息，测试仅发往指定测试目标，立即推送会实际发送到接收群。

升级前建议备份整个 `data/plugin_data/astrbot_plugin_cs_match/`，至少保留 `cs_data.json` 和已生成的 `qq_daily_players.sqlite3`。配置导出包含自定义配置和群设置，不包含凭据、通知状态或抽签数据库。已有配置与发送记录保留。
