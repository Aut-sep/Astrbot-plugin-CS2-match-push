# 插件安装包体积

AstrBot 插件市场安装或更新出现 `Plugin package exceeds the 16 MiB limit` 时，增大服务器磁盘空间不能缩小下载包。发布前在仓库根目录运行：

```console
python tools/check_package_size.py
```

脚本根据当前 Git 追踪文件和未被忽略的新文件，估算提交后的 GitHub 源码 ZIP，同时检查 ZIP 与解压文件总量均小于 16 MiB。它遵循文件的 `export-ignore` 属性，不打包 `.git`、运行缓存和已忽略文件；它不代表已经发布到市场的包。完成提交、推送后，市场才能下载到这些更改。

## 本地图片与压缩

插件随包保留完整的 127 张选手照片和 127 张带成就文字的紧凑头像，不需要安装后从 HLTV、GitHub 或其他图片服务下载。赛程、赛事和战队相关的本地图片也继续包含在包内。

- `player_photos/` 是选手资料和旧抽签快照引用的照片路径，也是重新生成紧凑头像的素材。
- `player_cards/` 是日常展示优先使用的头像，包含裁切后的照片和成就文字。

两套图片与插件图标采用最多 256 色的透明 PNG，文件名、像素尺寸和 PNG 格式保持不变，公开图片地址与本地图片回退逻辑不变。颜色量化属于有损压缩；透明背景、照片和成就文字仍保留，放大查看时可能存在细微色差。赛事图片和战队图标不做颜色量化。

添加新照片或重新生成头像后，可在开发环境安装压缩工具并运行：

```console
python -m pip install imagequant==1.1.5
python tools/optimize_package_images.py
python tools/check_package_size.py
```

`imagequant` 只供发布前处理图片，不是插件运行依赖。压缩脚本只处理本地文件，跳过已经量化的 PNG，避免反复量化造成画质损失；如果图片未达到预设质量下限，会停止并报错。更新图片后仍应检查包体积，并抽样检查透明边缘、肤色和成就文字。
